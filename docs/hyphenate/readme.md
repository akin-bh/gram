# Hyphenate track material

Reference material from the CalHacks Hyphenate track, kept for the team.

- [`calhacks-hyphenate-track.txt`](calhacks-hyphenate-track.txt): the official track brief, including how submissions are judged and what to submit.
- [`workshop/transcript.md`](workshop/transcript.md): Fathom's automatic transcript of the "Beyond Agentic Harnesses" workshop, October 21, 2026. It has not been checked word by word against the recording.
- [`workshop/workshop-slides.md`](workshop/workshop-slides.md): the 21 workshop slides as Markdown, with [per-slide files](workshop/slides/index.md), rendered slide images, and the [original PDF](workshop/source/workshop-slides.pdf).

The slides and recording belong to Hyphenate, and the transcript names workshop speakers and attendees. Remove this folder before making the repository public.
